# محرر الرقيم التربوي — تطبيق Android Native (Kotlin & Jetpack Compose)

المنصة الموحدة لإعداد وتحرير الوثائق والامتحانات المدرسية المعيارية A4 مبنية بالكامل بنظام **Android Native** باستخدام **Kotlin** و **Jetpack Compose** معمارية **Offline-First**.

---

## الميزات الرئيسية

1. **Native Jetpack Compose UI**: واجهات مستخدم عربية كاملة RTL متوافقة مع Material 3.
2. **محرك طباعة وPDF أصلي (A4 Vector Engine)**: توليد ملفات PDF حقيقية وطباعة فورية عبر `PrintDocumentAdapter` بدقة متناهية.
3. **قاعدة بيانات محلية (Room Database)**: تخزين ومزامنة الامتحانات، الشهادات، الكتب والملازم، وسجلات الحضور والدرجات محلياً دون الحاجة لاتصال بالإنترنت.
4. **الأقسام والخدمات المتكاملة**:
   - **محرر الامتحانات**: إعداد وتنسيق الاختبارات المعيارية وفق النماذج الوزارية.
   - **الكشوفات والنتائج**: رصد درجات الطلاب ومبيضات النتائج والتقديرات.
   - **الشهادات والوثائق**: شهادات الإجازة، التفوق، والاعتماد الأكاديمي.
   - **الكتب والمذكرات**: تأليف الملازم والكتيبات التعليمية وتنسيق الصفحات.
   - **الحضور والمواظبة**: حصر الغياب اليومي والانضباط المدرسي.
   - **المستندات الرسمية**: إعداد المذكرات الإدارية والتعاميم والقرارات.
   - **مركز القوالب**: قوالب امتحانية وشهادات جاهزة للاستخدام الفوري.
   - **بنك الأصول**: إدارة الشعارات والأختام والتواقيع والخطوط.
   - **إعدادات المنظومة**: تخصيص بيانات المدرسة والمعايير الرسمية.

---

## المتطلبات والتشغيل

- **Target SDK**: 34 (Android 14) / **Min SDK**: 24 (Android 7.0)
- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose (Material 3)
- **Database**: Room Database (SQLite)
- **Build System**: Gradle Kotlin DSL
